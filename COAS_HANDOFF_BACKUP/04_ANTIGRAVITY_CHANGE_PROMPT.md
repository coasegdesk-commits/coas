### 공통 규칙

- 관련 코드를 먼저 읽고 최소 범위로 수정하세요.
- 기존 사용자 변경을 덮어쓰지 마세요.
- 이미지 이름이나 제품 ID를 추측해서 바꾸지 마세요.
- 장바구니·결제·주문·회원 기능이 필요하면 기존 구현 여부부터 확인하세요.
- 새 결제사 연결, 고객 데이터 저장, DB 변경, 대규모 구조 변경은 사전 승인받으세요.
- 비밀값이나 개인정보를 로그·분석 이벤트로 전송하지 마세요.
- 수정 후 타입 검사·빌드와 해당 기능의 성공·실패 경로를 확인하세요.
- 변경 파일, 검증 결과, 미확인 사항을 설명하세요.
