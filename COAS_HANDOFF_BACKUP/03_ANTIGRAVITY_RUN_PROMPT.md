# 3단계 — Antigravity에서 실행 환경 준비

2단계 조사 결과를 확인한 후 입력하세요.

---

앞서 조사한 코아스 원본을 보존하면서 현재 환경에서 실행할 수 있도록 최소한의 호환성 수정만 진행하세요. 새 디자인이나 쇼핑몰 기능은 추가하지 마세요.

## 원본 보호

검증 완료 후 별도 작업 브랜치 또는 안전한 원본 복사본을 준비하세요. 기존 사용자 변경을 되돌리거나 덮어쓰지 마세요. 변경할 파일과 이유를 먼저 짧게 설명하세요.

## 설치·실행

- package.json의 engines 및 Vite 요구사항을 확인하세요. 이 프로젝트의 기존 런타임은 Node 20 계열이며, Vite 7에는 Node 20.19+ 또는 22.12+ 등 지원 버전이 필요합니다. 실제 의존성이 요구하는 버전을 우선하세요.
- package-lock.json과 보안 overrides를 보존하고 npm ci로 설치하세요.
- 설치 실패를 해결하려고 잠금파일을 삭제하거나 보안 차단을 우회하지 마세요.
- Windows 등에서 NODE_ENV=... 문법이 호환되지 않으면 필요한 실행 부분만 조정하세요.
- .env.example은 이름 참고 자료입니다. 환경변수를 어떻게 안전하게 로드할지 명시하세요. 실제 값을 채팅·코드·로그에 넣지 마세요.
- 사용자는 비밀정보를 로컬 환경설정 또는 해당 도구의 비밀정보 관리 방식으로 직접 제공해야 합니다.
- DATABASE_URL과 AI 설정이 없으면 서버 초기화가 실패할 수 있습니다. 빈 설정으로 정상 실행됐다고 주장하지 마세요.
- Replit 관리형 AI 연결을 외부에서도 재사용할 수 있다고 가정하지 마세요. 외부 제공업체 연결 변경이 필요하면 사용자에게 선택과 승인을 요청하세요.
- 프런트엔드 API는 같은 서비스의 /api/... 상대 URL을 유지하세요.
- Replit 전용 개발 플러그인은 원본 동작을 확인한 뒤 조건부 처리하세요. 서비스 콘텐츠와 혼동해서 삭제하지 마세요.

## 보존

디자인, 코아스 브랜드, 한/영 콘텐츠, 제품 순서, 이미지 크기, 호버 효과, 상세 링크, 확대 보기, SEO와 기존 커스텀 분석 이벤트를 보존하세요.

Replit 밖에서는 분석 추적기가 자동 주입되지 않을 수 있습니다. 기존 안전한 이벤트 래퍼는 유지하고, 승인 없이 새 추적기를 추가하지 마세요.

## 데이터 안전

이 ZIP에는 운영 DB와 실제 고객 데이터가 없습니다.
DB를 새로 만들거나 운영 DB에 쓰기 작업을 하기 전에 대상 환경과 백업·복원 계획을 승인받으세요.
npm run db:push, 자동 시딩, DROP, TRUNCATE, 강제 마이그레이션을 자동 실행하지 마세요.
테스트를 위해 실제 고객 데이터나 문의를 생성하지 마세요.

## 검증

1. npm run check, npm run build 및 기존 안전한 테스트
2. npm run dev와 페이지 직접 방문·새로고침
3. 제품 이미지 누락, 카드 링크, 확대, 호버
4. 검색·카탈로그 신청의 성공/빈 결과/실패 경로
5. PC와 모바일, 브라우저 콘솔
6. SEO 주소가 실제 새 도메인과 일치하는지 확인
7. 기존 이벤트가 중복 발생하거나 개인정보를 전송하지 않는지 확인

외부 API 호출·유료 기능·운영 데이터 생성 테스트는 승인 전 수행하지 마세요.
검증 불가능한 기능은 이유를 보고하세요.
기존 오류와 이번 변경으로 새로 생긴 오류를 분리하세요.

끝으로 실행 명령, 설정해야 할 변수 이름, 변경 파일, 테스트 결과, 미해결 사항, 원본 복구 방법을 정리하세요.
